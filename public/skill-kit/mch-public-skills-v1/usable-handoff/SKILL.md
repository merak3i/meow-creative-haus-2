# Usable handoff

## Inputs

The completed work, intended recipient, available files and destination.

## Workflow

1. Identify what the recipient needs to copy, open, run or review.
2. Put short actionable text in the response. Link binary or long artifacts with their real filenames and explain their purpose.
3. Separate final content from commentary so there is one unambiguous copy target.
4. Verify file existence and the claimed state. Distinguish saved, submitted, deployed and checked.
5. For commands, use the recipient's actual platform and working directory; explain placeholders rather than inventing values.

## Deliver

A usable final answer, verified artifact links and the smallest necessary next step.

## Limits

Do not paste secrets or bulk private records to make a handoff self-contained. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Package this completed work for the person who will publish it. Give one final copy block, file links and the remaining checks.
