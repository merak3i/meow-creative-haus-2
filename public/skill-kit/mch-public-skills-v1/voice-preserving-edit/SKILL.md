# Keep my voice

## Inputs

The draft, audience, destination and optional examples of the writer's own prose.

## Workflow

1. Read the whole draft before editing. Identify the argument, useful details and recognizable voice choices.
2. Fix passages that obstruct understanding. Preserve opinions, uncertainty and deliberate roughness supported by the draft.
3. Check every number, attribution and claim against supplied material. Flag gaps instead of filling them with plausible facts.
4. Read the result as the intended recipient. Remove repetition without making every paragraph sound alike.

## Deliver

The complete edited draft and a short explanation of substantive changes.

## Limits

An editing pass cannot establish authorship or guarantee that a detector will classify text a particular way. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Edit this draft for an industry newsletter. Keep my uncertainty and conversational rhythm. Add no facts. Return one final version.
