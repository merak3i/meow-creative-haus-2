# Content to format

## Inputs

Source notes, audience, platform, brand constraints and requested format.

## Workflow

1. Choose one main idea from the supplied evidence. Label hypothetical examples and distinguish them from observed results.
2. Map the reading sequence before drafting: why read, what matters, what the reader can do.
3. Adapt density to the format. Give each slide a job; use captions for context that would overload the image.
4. Check claims and inspect exported visuals for readable type, clipping and missing elements.
5. Deliver the requested files and caption. Publish only when that destination and action are authorized.

## Deliver

Final copy, the requested visual sequence, caption and evidence notes where needed.

## Limits

This skill supplies a workflow, not platform access or a promise of reach. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Turn these notes into a six-slide square carousel for operations managers. Label invented examples and keep the source claims intact. Do not post it.
