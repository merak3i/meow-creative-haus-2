# Compact documents

## Inputs

Content, intended use, brand reference, page size and page budget; use three pages when no budget is specified.

## Workflow

1. Respect an explicit length request. Otherwise plan for at most three pages and choose the facts each page must carry.
2. Use a grid, hierarchy and tables only where they help comparison. Remove duplicated explanation before reducing type size.
3. Use supplied brand guidance or a readable light layout. Keep labels, units, citations and caveats near their claims.
4. Render every page to an image and inspect all of them. Correct clipping, overlap, broken glyphs and unintended page breaks.
5. If the content cannot fit legibly, explain the tradeoff and propose prioritization or a longer version; do not silently drop essential content.

## Deliver

The requested document, a brief QA result and any explicitly unresolved constraints.

## Limits

A rendering tool is required to certify visual QA. Text extraction alone does not verify layout. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Make a three-page decision brief from these notes. Prioritize readable comparisons and inspect each rendered page before delivery.
