# Reference-safe edits

## Inputs

The reference document, exact requested changes and authoritative replacement values.

## Workflow

1. Inventory the requested fields and the content that should remain unchanged.
2. Use authoritative values. Check dates, units, totals and rounding affected by the edits; do not fabricate tax or banking details.
3. Make the smallest change that preserves the reference structure and style.
4. Compare the result against the original for accidental content changes, then render and inspect every output page.
5. Return the edited file with a short change list and any unresolved arithmetic or missing inputs.

## Deliver

An updated document, field-level change summary and visual verification status.

## Limits

Document preparation is not accounting or legal certification and does not authorize payments. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Update only these fields in the attached reference. Recalculate affected totals, preserve the layout and inspect the exported pages.
