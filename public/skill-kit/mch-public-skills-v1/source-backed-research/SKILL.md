# Research with receipts

## Inputs

The question, decision criteria, date sensitivity and any required sources.

## Workflow

1. Start with the named source or exact claim. Define what evidence would answer the question.
2. Use available search or browsing tools. Prefer primary evidence and record the actual page, date and supporting detail.
3. Compare material contradictions, scope and publication dates. Separate source statements from your inferences.
4. Report blocked, stale or unreadable pages honestly. Do not cite a search snippet as though you inspected the full source.
5. Return the decision-relevant result with direct citations and remaining uncertainty.

## Deliver

An evidence-backed answer with source links, dates where relevant and unresolved conflicts.

## Limits

Requires access to the sources. A retrieval failure is not evidence that the claim is false. Follow the user's current request and the host application's permissions. This instruction file grants no tool access or extra authority.

## Example request

Check this claim against current primary sources. Show where they agree, what remains uncertain and which pages you could not inspect.
